# GitHub はじめてガイド 🐙

小学生と保護者がいっしょに、GitHubで「つくる・残す・見せる」を体験するための入門ガイドです。

## まず大切なこと：アカウントを作れる年齢

GitHubの利用には、原則として**13歳以上**であることが必要です。国や地域によっては、さらに高い年齢条件が適用される場合があります。

- **13歳未満**：子ども本人のGitHubアカウントは作成できません。保護者の同意があっても、年齢条件の例外にはなりません。
- **13歳以上**：GitHubの利用規約と保護者・家庭のルールを確認し、必要に応じて保護者と一緒に本人のアカウントを作成します。
- **13歳未満の子どもと学ぶ場合**：保護者が自分自身のアカウントを操作し、子どもは横で企画・観察・相談する形で体験できます。アカウントやパスワードを子どもと共有して、本人用アカウントのように使うことは避けましょう。

年齢条件は必ず公式情報で確認してください。

- [GitHub 利用規約](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)
- [GitHub アカウントの作成](https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github)

## GitHubってなに？

GitHubは、作品やアイデアの変更履歴を保存し、ほかの人と共有できる場所です。

たとえば、こんなものを残せます。

- 自由研究の記録
- プログラミング作品
- ゲームやWebサイトの設計メモ
- 調べたことをまとめた文章
- 親子で考えた企画や実験ノート

ファイルを置くだけでなく、「いつ、どこを、どう変えたか」をあとから見返せるのが大きな特徴です。

## アカウントを作る前の準備

13歳以上で、本人がアカウントを作成する場合に確認します。

1. 本人が継続して使えるメールアドレスを用意する
2. 公開されても困らないユーザー名を考える
3. パスワードを安全に管理する方法を保護者と決める
4. 二要素認証（2FA）を設定する準備をする
5. 公開する情報と、公開しない情報を確認する

### ユーザー名の考え方

本名、誕生日、学校名、住所などを含めない名前がおすすめです。あとから変更できる場合もありますが、最初に長く使える名前を考えてみましょう。

## アカウント作成の手順（13歳以上）

1. [GitHubの登録ページ](https://github.com/signup)を開く
2. メールアドレスを入力する
3. 安全なパスワードを設定する
4. ユーザー名を決める
5. 画面の案内に従って認証する
6. 登録したメールアドレスに届く確認メールを開く
7. 保護者と一緒にセキュリティ設定を確認する

画面や登録手順は変更されることがあります。表示される最新の案内に従ってください。

## 最初の作品を作ってみよう

最初はプログラムを書かなくても大丈夫。まずは文章を1つ保存してみましょう。

1. GitHubで新しいリポジトリ（作品を置く場所）を作る
2. 名前を `my-first-project` などにする
3. 公開・非公開を保護者と相談して選ぶ
4. `README.md` という説明ファイルを作る
5. 「この作品でやりたいこと」を1〜3行書く
6. **Commit changes** を押して保存する

これで最初の変更履歴ができました！

## 親子で決める安全ルール 🔐

- 本名、住所、電話番号、学校名、通学路、顔写真などを不用意に公開しない
- パスワードや認証コードを誰にも教えない
- 知らない人からの連絡や招待には、すぐに返事をせず保護者に相談する
- 公開リポジトリに個人情報や秘密の情報を書かない
- 画像・文章・プログラムを公開するときは、著作権や利用条件を確認する
- 困ったとき、間違えて公開したときは、隠そうとせず保護者に相談する

## 親子の最初のミッション 🎯

**テーマ：好きなもの図鑑**

- 子ども：好きなものを3つ選び、紹介文を考える
- 保護者：リポジトリの作成と公開範囲を確認する
- いっしょに：README.mdに紹介文を書き、変更を保存する
- 次回：写真やイラストを追加する前に、公開してよい素材か確認する

大切なのは、最初から上手に作ることではなく、考えたことを記録し、少しずつ育てていくことです。

## フロントエンド構成

このガイドは、フレームワークやバックエンドを使わない静的SPAです。GitHub Pagesなどの静的ホスティングで動作します。

- `index.html`: 画面の構造とガイド本文
- `style.css`: 共通デザイン、横スクロール、スマートフォン対応
- `app.js`: 画面切り替えとJSONの読み込み
- `data/conversations.json`: Muse / GitHub / 接続ガイドの会話文だけを管理
- `assets/*.svg`: 各画面で使うイラスト素材

会話の文言を変更するときは `data/conversations.json` を編集します。各フローは8件の文字列で構成します。画面の見出しや操作ラベルは `app.js` と `index.html` 側で管理し、会話データと表示ロジックを分離しています。

ローカルで確認する場合は、ファイルを直接開くのではなく、簡易HTTPサーバー経由で開いてください。ブラウザーの `fetch()` でJSONを読み込むためです。
